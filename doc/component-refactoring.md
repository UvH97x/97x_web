# ページ間の共通コンポーネント（2026-09-05）

既存の見た目・挙動を維持し、ページ固有のデータや数値変換を呼び出し側に残して共通化した。

| 重複していた機能 | 共通コンポーネント | 適用先 |
| --- | --- | --- |
| 見出し・説明・カード一覧 | `src/app/(app_like)/simulators/_components/SimulatorCatalog.tsx` | シミュレーター総合・機械学習・統計の一覧3ページ |
| タイトル・説明・任意のアイコンを持つリンクカード | `src/components/ui/LinkCard.tsx` | ホームの既存 `LinkBlock`、シミュレーター一覧 |
| ラベル・値表示・数値変更通知を持つスライダー | `src/components/ui/RangeField.tsx` | 多項式回帰の操作パネル・モデルパラメータ、統計の操作パネル |

## 利用方針

- 一覧ページはタイトル・説明・リンクデータを `SimulatorCatalog` に渡す。
- `LinkCard` の `home` / `catalog` は既存のスタイルを保持する。既存の `LinkBlock` は `PageLink` を受け取る互換ラッパーとして残す。
- `RangeField` はネイティブのスライダー値を数値として通知する。対数変換・丸め・表示桁数は利用側で指定する。`inline` / `stacked` / `detailed` で既存の配置を保持する。
- スライダーのラベルと入力は `useId` で関連付ける。

## 共通化を見送ったもの

- 各シミュレーターのグラフ：Chart.js・Canvas・SVGで描画方法と責務が異なる。
- 再生・停止・リセット：回帰はデータ再生成と実行切り替え、勾配降下法は履歴・ステップ操作を伴い、挙動が異なる。
- 記事一覧とアプリ一覧：今回のカード一覧とは構造・表示が異なるため、無理に統合しない。

## 検証結果

- TypeScript 型チェック、本番ビルドが成功。
- 変更前のコミットと変更後のコンポーネントをレンダリングし、16ケースのHTMLを比較。ラベルの関連付けと属性順以外は一致。
- 次数の変更、正則化係数・ステップ幅の対数変換、統計のサンプル数の対数変換と丸めを操作コールバックで確認。
